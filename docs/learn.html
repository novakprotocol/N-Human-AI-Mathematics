Path 2 · ABF-001

The rule that makes a bit machine simpler

A Boolean output can become simpler when inputs are restricted by one exact XOR relation.

Try a three-bit doorway

The toy output is f(x₁,x₂,x₃)=x₁x₂ XOR x₃. Without a restriction it can be 0 or 1. Force x₃=x₁x₂, and the two terms always cancel.
