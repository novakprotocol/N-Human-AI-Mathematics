The purpose

Not a victory page. A review surface.

The repository is designed to make precise disagreement possible.

01

Exact claims

Every promoted paper separates definitions, theorem statements, proof status, computation, formal scope, limitations, and release state.

02

Inspectable evidence

Programs, tests, source commits, hashes, receipts, failed runs, and repairs are preserved so readers can reproduce or challenge the record.

03

Bounded language

Public release does not mean peer review, worldwide novelty, full formal verification, journal acceptance, or identification of a particular model or provider.

Featured research

HINC-001

Candidate theorem · public review

Hidden Infinitesimal Noncommutativity

Two explicit characteristic-two Gerstenhaber endomorphism monoids share a crossing core but differ by an infinitesimal skew thickening and a clopen unit doubling.

Ordinary field-valued points can make a symmetry system appear commutative and central while infinitesimal test rings expose noncommutativity and a smaller scheme-theoretic center.

The collaboration

Human judgment, LLM exploration, machine checks.

The roles overlap, but responsibility does not.

  1. Human direction

    Matthew selected problems, imposed constraints, challenged shallow answers, judged significance, ran release gates, and retained publication authority.

  2. LLM assistance

    Large language models proposed mathematical directions, decompositions, proofs, programs, tests, counterexample searches, literature queries, and editorial structure.

  3. Independent tools

    Python, C, symbolic systems, Git, GitHub, and Lean supplied bounded evidence routes rather than authority.

  4. Correction discipline

    Failures were preserved, causes classified, repaired source assigned a new identity, and PASS recorded only after a fresh run.

Historical boundary

This is not the first human–AI mathematics project.

Public precedents include machine-learning-guided conjecture discovery, LLM-guided program discovery, LLM-assisted proof work, human–LLM–symbolic discovery logs, and AI-generated formal proof repositories.

The narrower claim is that this repository is one openly documented, commit-anchored case study combining role disclosure, claim ledgers, correction history, executable evidence, formal-proof boundaries, and adversarial review.
